What is a PWA?

A Progressive Web Application (PWA) is a website that can work more like an app. It uses web technologies such as HTML, CSS, and JavaScript. A PWA can have an icon on a phone or computer and can open in its own window after a user installs it.

PWAs can also work when the internet connection is weak or unavailable. A service worker can save important files in a cache so the page can load offline. A web app manifest tells the browser the app's name, icon, starting page, and display mode. Responsive design helps the same app fit both small and large screens.
